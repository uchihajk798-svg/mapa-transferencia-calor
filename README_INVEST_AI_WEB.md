# INVEST AI Web 0.6

Preparado para validar os recursos de IA educativa e Global Intelligence. O código completo está em INVEST_AI_web_source.zip.

A IA do site é interpretador transparente de regras, não modelo generativo. Consulta GDELT, Banco Central e CoinGecko quando disponíveis. Sem recomendação ou cotações inventadas. A IA generativa está pronta somente no backend não publicado, exigindo OPENAI_API_KEY segura, autenticação e serviço HTTPS.
